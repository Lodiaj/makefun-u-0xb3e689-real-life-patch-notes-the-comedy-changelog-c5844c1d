# Real-Life Patch Notes: The Comedy Changelog

One line, a software patch note for a bug in human biology:

> v3.0.2: fixed a bug where the human body requested a full night of sleep, then woke up at 3 a.m. to replay an embarrassing conversation from 2014.

It reads like a real release note — version number, terse engineering register, a fix stated as if it shipped — and names a bug everyone recognises: the body asks for sleep, then wakes you at 3 a.m. to replay something embarrassing from a decade ago. No padding, every word working, 146 characters.

`main.ts` writes exactly that line (no trailing newline) to `/output/entry.txt`, checks it is 1–160 UTF-8 characters, and round-trip verifies the file on disk is byte-identical to the line.
